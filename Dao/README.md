# 游戏官网

一个简洁美观的游戏官网，包含背景图和 TapTap 下载按钮。

## 文件说明

- `index.html` - 主页面文件
- `styles.css` - 样式文件
- `background.jpg` - 背景图片（需要您自己添加）

## 如何配置背景图

1. 将您的背景图片命名为 `background.jpg`
2. 将图片文件放在与 `index.html` 相同的目录下
3. 如果您的图片文件名不同，请修改 `styles.css` 文件中的第 13 行：
   ```css
   background-image: url('background.jpg');
   ```
   将 `background.jpg` 替换为您的图片文件名。

## 支持的图片格式

- JPG/JPEG
- PNG
- WebP
- 其他浏览器支持的图片格式

## 自定义样式

如果需要修改按钮样式、文字颜色等，可以编辑 `styles.css` 文件。

## 使用说明

直接在浏览器中打开 `index.html` 即可查看网站效果。
